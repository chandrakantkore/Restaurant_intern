# 📊 Restaurant Data Analysis & Prediction

A comprehensive **Restaurant Data Analysis** project completed during my internship. This project explores restaurant datasets using Python to discover customer preferences, restaurant trends, ratings, cuisines, pricing, and business insights through Exploratory Data Analysis (EDA). Inspired by common restaurant analytics internship tasks. 0

---

## 🎯 Objectives

- Clean and preprocess restaurant data
- Perform Exploratory Data Analysis (EDA)
- Analyze restaurant ratings
- Study cuisines and customer preferences
- Analyze pricing and online delivery
- Generate business insights using visualizations

---

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/chandrakantkore/Restaurant_intern.git
```

Navigate to the project

```bash
cd Restaurant_intern
```

Install dependencies

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook

```bash
jupyter notebook
```
